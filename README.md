# Temirlan Yelaman Portfolio Site

Files:
- index.html
- about.html
- portfolio.html
- contact.html
- styles.css
- script.js
- specification.txt

To run:
1. Open this folder in VS Code.
2. Right-click index.html.
3. Click "Open with Live Server".

Important:
- Add your resume as `resume.pdf` in the same folder if you want the Resume link to work.
- The contact form uses mailto, which opens the user's email app.
- For a production contact form, replace it with Formspree, Netlify Forms, or your own backend.
