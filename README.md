# Temirlan Yelaman Portfolio Site

This version uses Netlify Forms for the contact page.

To use:
1. Upload these files to a GitHub repository.
2. Deploy the repository on Netlify.
3. In Netlify, open your project and check that the contact form is detected.
4. Add an email notification for form submissions.
5. Add your resume as resume.pdf in the project root.

Local testing:
Open index.html with VS Code Live Server. Netlify Forms only processes submissions after deployment on Netlify.
